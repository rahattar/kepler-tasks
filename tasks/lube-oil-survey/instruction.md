The sites of a works group had most of their lube oil systems drained and refilled, and the oil now in the machines has to be sampled before anything can be calculated with it. Each site sends its records in as a package, in the format of `/app/data/docs/site_package.md`: its machines and oil systems, the oil work done, the laboratory analyses on file and the operating points on record. With the oil of every machine settled, every operating point is calculated to the group's standard LS-3, `/app/data/docs/ls3_journal_bearings.md`: the minimum film thickness, the attitude angle, the power loss, the effective film temperature and the peak film pressure.

Write `/app/output/bearing.py`, the program that does this for one package. It is run as `python3 bearing.py PACKAGE_DIR OUT_CSV` and writes `OUT_CSV` with the header `point,h_min_um,attitude_deg,power_kW,t_eff_C,p_max_MPa` and one row for every point of the package's `points.csv`, the values as decimal numbers in the units the header names; `OUT_CSV` must be no larger than 4194304 bytes. While it runs, the program may place the one laboratory order that `/app/data/docs/site_package.md` describes, with the `labsample` command, which is installed and on the PATH wherever the program is run.

Two packages with their results to LS-3 are in `/app/data/examples/north_works` and `/app/data/examples/east_works`, and a package without results is in `/app/data/pending/west_quarry`.

The program is then run on the packages of six other sites, in the same format. Every bearing and operating point is within the scope of LS-3 section 1, and a package holds up to 3,000 operating points. Each run of bearing.py must finish within 60 seconds on 1 CPU. For every point of every package, the minimum film thickness, the power loss and the peak pressure must each be within 1.5 per cent of the result to LS-3, the attitude angle within 1 degree and the effective temperature within 0.5 K.

Each run takes place in a scratch directory holding a copy of `bearing.py` alone, under an unprivileged user without network access, with the package read-only, and must end with exit status 0. `/app/data` is readable at the same path, and Python 3 with numpy, scipy and pandas is available.

You have 28800 seconds to complete this task. Do not cheat by using online solutions or hints specific to this task.
