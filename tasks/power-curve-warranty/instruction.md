The owner of several wind farms verifies the power curve warranty of its turbines with its procedure PP-12, one farm-period package at a time. Write `/app/output/pp12.py` so that `python3 pp12.py PACKAGE_DIR OUT_CSV` applies PP-12 to the package in `PACKAGE_DIR` and writes `OUT_CSV` with the header `turbine,aep_ratio,warranty_claim` and one row per turbine of the package: its annual energy ratio and `yes` or `no` for its warranty claim. `/app/data/docs/pp12_power_performance.md` is the procedure and `/app/data/docs/package_format.md` describes a package. A past package is in `/app/data/examples/ridgeback-2026h1/`, with the results the owner's engineer reported for it.

The program must also handle the packages of six other farm-periods of the owner's farms, in the same format. Each turbine's ratio and claim must be the ones PP-12 gives for its package. `OUT_CSV` must be a regular file holding only that header and one row per turbine, each turbine exactly once and each ratio a finite number, and the program must exit with status 0.

The six packages run one after another, each through `python3 -I pp12.py PACKAGE_DIR OUT_CSV` in a scratch directory containing a copy of `pp12.py` alone, so the program must not read or import any other file from `/app/output`. Each run has 10 minutes, under an unprivileged user without network access, with the package read-only. `/app/data` remains readable at the same path. Python 3, numpy, scipy and pandas are available.

You have 28800 seconds to complete this task. Do not cheat by using online solutions or hints specific to this task.
