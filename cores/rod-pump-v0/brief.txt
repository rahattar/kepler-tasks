Work only inside PROBE. Do not read, list or open anything outside PROBE. Everything you need is under PROBE/app.

The fields of an oil producer lift their wells with sucker-rod pumps and calculate them to the company's standard RL-2, `PROBE/app/data/docs/rl2_rod_lift.md`: from the dynamometer cards on record of each well, the plunger stroke, the liquid lifted and the peak and minimum polished rod loads the well will have at every setting of its pumping unit in the field's setting table. A field sends its records in as a package, in the format of `PROBE/app/data/docs/field_package.md`.

Write `PROBE/app/output/rodlift.py`, the program that makes this calculation for one package. It is run as `python3 rodlift.py FIELD_DIR OUT_CSV` and writes `OUT_CSV` with the header `setting,plunger_stroke_m,liquid_m3_d,pprl_kN,mprl_kN` and one row for every setting of the package's `settings.csv`, the values as decimal numbers in the units the header names.

Two packages with their results to RL-2 are in `PROBE/app/data/examples/north_lease` and `PROBE/app/data/examples/creek_unit`, and a package without results is in `PROBE/app/data/pending/mesa_block`.

The program is then run on the packages of six other fields, in the same format. Every well and setting is within the scope of RL-2 section 1, and a package holds up to 2,500 settings. Each run of rodlift.py must finish within 45 seconds on 1 CPU. For every setting of every package, the plunger stroke and the liquid must each be within 3 per cent of the result to RL-2, and the peak and the minimum polished rod load each within 3 per cent of the peak polished rod load.

Each run takes place in a scratch directory holding a copy of `rodlift.py` alone, so the program cannot read any other file you leave, and must end with exit status 0. Python 3 with numpy, scipy and pandas is available.

This machine is shared with other jobs, so judge your program's speed by its CPU time (user plus system, as `time` reports it), not by the wall clock. Write any scratch files under PROBE/app/work. When you are done, report what you did, how you checked it and how long a run takes.
