# Halvorsen pump set - datasheet extract

- Rated point at 1480 rpm: 300 L/s at 85.0 m; efficiency 84 percent at the rated point.
- Head-flow curve at rated speed:

| flow (L/s) | head (m) |
|---|---|
| 0 | 110.5 |
| 50 | 109.8 |
| 100 | 107.7 |
| 150 | 104.1 |
| 200 | 99.2 |
| 250 | 92.8 |
| 300 | 85.0 |
| 350 | 75.8 |
| 400 | 65.2 |

- Homologous characteristics for transient analysis, normal zone (speed and flow positive), with alpha = speed / rated speed and v = flow / rated flow: head / rated head = 1.30 alpha^2 - 0.30 v^2; torque / rated torque = 0.45 alpha^2 + 0.55 alpha v. Rated torque = rho g Q H / (efficiency x rated angular speed).
- Moment of inertia: impeller and shaft 7.0 kg m2. Motor (4 pole): rotor 13.0 kg m2. No flywheel.
- Non-return valve: tilting disc with dashpot, closes at flow reversal without slam.
