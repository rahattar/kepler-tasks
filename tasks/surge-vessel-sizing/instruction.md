The water utility designs an air vessel separately for each pumping main under its MS-SV surge standard. Write `/app/output/surge.py` so that `python3 surge.py MAIN_DIR OUT_JSON` reads the package in `MAIN_DIR`, sizes the vessel for that main, and writes `OUT_JSON` with `vessel_volume_m3` for the total vessel volume and `gas_volume_m3` for the gas volume set in steady operation. The governing standard is `/app/data/docs/ms_sv_surge_standard.md`, and `/app/data/docs/package_format.md` explains the package format. One earlier main is provided in `/app/data/examples/kestrel-lane/` along with the design reported by the utility's engineer.

The same program must work on six other main packages in the same format. For each one, the resulting design must satisfy MS-SV for the main as installed. `OUT_JSON` must be a regular file no larger than 65536 bytes and contain one JSON object with only the two required keys, each appearing exactly once. Both values must be finite positive numbers, `gas_volume_m3` must be smaller than `vessel_volume_m3`, and the program must exit with status 0.

Those six packages are processed one after another with `python3 -I surge.py MAIN_DIR OUT_JSON`. Each run takes place in a scratch directory containing a copy of `surge.py` alone, so it cannot import or read any other file from `/app/output`. The package is read-only, the process runs as an unprivileged user without network access, and each run may take up to 15 minutes. `/app/data` remains available at the same path. Python 3, numpy, scipy and pandas are installed.

You have 28800 seconds to complete this task. Do not cheat by using online solutions or hints specific to this task.
