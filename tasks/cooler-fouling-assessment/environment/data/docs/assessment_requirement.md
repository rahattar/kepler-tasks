# Bank fouling assessment: requirement (process engineering)

For every cooler, report the as-found fouling resistance on 2026-10-26, before any cleaning that day:
R_f = 1/U_as_found - 1/U_clean at the same flows, in m2K/kW, with U referred to the unit's actual heat-transfer
area (open tubes only). One figure per unit, the best estimate the records and the day's tests support. The
cleaning plan for the 2027 outage is built from these figures and each unit's figure decides whether that unit is
opened, so give a single number per unit rather than a range.
