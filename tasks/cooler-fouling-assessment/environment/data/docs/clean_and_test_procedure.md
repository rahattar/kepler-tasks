# Clean-and-test: procedure and accuracy (maintenance contractor)

On 2026-10-26 the contractor can clean and test three coolers in total across the bank; each slot takes a unit
out of service for a shift. A slot is an as-found performance test with calibrated portable instruments
(clamp-on ultrasonic flowmeter on the water line, +-0.3 %; reference RTDs strapped at the four nozzles,
+-0.03 K), with the DCS readings logged at the same time; then the bundle is hydroblasted and the test repeated.
Both tests run at the unit's normal flows. The unit returns to service clean.

The report gives, for the as-found and the after-cleaning test, the reference-instrument flows and four
temperatures and the DCS flows, temperatures and tube-side differential pressure.
