Work only inside PROBE/app. Do not read, list or open anything outside PROBE/app.

A utility calculates the supply temperatures and the delivered heat of its hot-water heat networks to its standard HN-3, `PROBE/app/data/docs/hn3_heat_networks.md`. A network's records come as a package in the format of `PROBE/app/data/docs/network_package.md`.

Write `PROBE/app/output/heatnet.py`, the program that makes this calculation for one package. It is run as `python3 heatnet.py PACKAGE_DIR OUT_CSV` and writes `OUT_CSV` with the header `point,value` and one row for every point of the package's `points.csv`, the result HN-3 section 6 defines for it as a decimal number.

Two packages with their results to HN-3 are in `PROBE/app/data/examples/harbour_east` and `PROBE/app/data/examples/mill_quarter`, and a package without results is in `PROBE/app/data/pending/station_park`.

The program will then be run on the packages of six other networks, in the same format, each within the scope of HN-3 section 1. Each run of heatnet.py must finish within 12 seconds on 1 CPU. Every temperature must be within 0.01 K of the result to HN-3, and every heat within 0.01 per cent of it or 0.01 kW, whichever is more.

Each run takes place in a scratch directory holding a copy of `heatnet.py` alone, with the package read-only, and must end with exit status 0. Python 3 with numpy, scipy and pandas is available.

This machine is shared with other jobs, so judge your program's speed by its CPU time (user plus system, as `time` reports it), not by the wall clock. Write any scratch files under PROBE/app/work. When you are done, report what you did, how you checked it and how long a run takes.
