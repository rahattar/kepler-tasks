Generator losses (OEM loss test certificate): L = 410 + 560 (S / 56.0)^2 kW, with S the apparent power in MVA. The
constant part covers friction, windage and core losses; the second part is the stator and rotor copper loss and the
stray load loss at the corresponding excitation.
