# Requirement: fatigue damage at the gusset weld toes (screen house)

For each screen S1-S10, the accumulated fatigue damage (Miner's sum per plant standard FS-07) at the monitored
drive-side gusset weld toe, from the weld's entry into service to the end of 2026-10-31. Each value must be within
20 % of the true damage.
