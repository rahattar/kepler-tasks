# Screen house: DDS-3073 vibrating screens S1-S10

- Double-deck horizontal screens, 3.0 m x 7.3 m, on steel coil springs. S8 and S10 have the larger drive (37 kW
  motor, identical on both, with the heavier exciter shafts); the others have the 30 kW drive. A twin-shaft unbalanced-mass exciter,
  driven by an induction motor at constant speed (register), sits on an exciter beam bolted to gussets welded to
  the side plates. The monitored weld is the drive-side gusset toe on the side plate.
- In service the screen runs well above the bounce resonance of its suspension (about 3 Hz on these screens); a
  start or a stop passes through it.
- Starts are direct on line; the motor reaches full speed in a few seconds.
- Stops: until 2026-03-02 the drives had no brake. On a stop the motor was switched off and the screen coasted
  down; the exciter's speed decayed close to exponentially. The coast-down was timed on each screen at
  commissioning (time for the exciter to fall from full speed to half speed):

  | screen | full to half speed, s |
  |---|---|
  | S1 | 11.4 |
  | S2 | 12.9 |
  | S3 | not timed |
  | S4 | 13.1 |
  | S5 | 13.6 |
  | S6 | 13.2 |
  | S7 | 9.7 |
  | S8 | not timed |
  | S9 | 13.8 |
  | S10 | not timed |

- Since 2026-03-02 every drive has a motor brake, which brings the exciter to standstill in about 5 s.
- Every start ends in a stop.
