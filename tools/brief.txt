You are studying the flare system of a process unit. Work only inside PROBE. Do not read, list or open
anything outside PROBE: not the repository it sits in, not any file about how this exercise was made.
Everything you need is under PROBE/app.

Unit 400 is a natural gas liquids recovery train. Its flare system has not been restudied since the unit's capacity increase in 2024, and a load study to the current issue of the plant standard is now due. The contingencies to be studied are the ones RP-7 names.

For each contingency, establish which of the unit's relief devices discharge at the same time, the total mass flow they put into the flare header, and the pressure that flow raises at the header's inlet. Plant standard RP-7 in `PROBE/app/data/docs/standard.md` governs the study.

The records are `PROBE/app/data/relief_valve_register.csv`, `PROBE/app/data/valve_history.csv`, `PROBE/app/data/fire_zones.csv`, `PROBE/app/data/flare_tie_ins.csv`, `PROBE/app/data/drive_schedule.csv`, `PROBE/app/data/control_valve_data.csv`, `PROBE/app/data/control_valve_trend.csv`, `PROBE/app/data/operating_record.csv`, `PROBE/app/data/instrument_schedule.csv`, `PROBE/app/data/sis_register.csv`, `PROBE/app/data/exchanger_data.csv`, `PROBE/app/data/pump_data.csv`, `PROBE/app/data/pump_test_record.csv`, `PROBE/app/data/gas_analysis.csv`, `PROBE/app/data/component_properties.csv`, `PROBE/app/data/fluid_properties.csv`, `PROBE/app/data/gas_properties.csv`, `PROBE/app/data/liquid_properties.csv`, `PROBE/app/data/modification_register.csv` and `PROBE/app/data/maintenance_log.csv`. The unit is described in `PROBE/app/data/docs/unit_400.md`, its vessels in `PROBE/app/data/docs/vessel_data.md`, the flare header and stack tip in `PROBE/app/data/docs/flare_system.md`, and the load study of 2019 in `PROBE/app/data/docs/flare_load_study_2019.md`.

The unit's test crew is on site for one shift and will run field tests for you. What it will run is in
`PROBE/app/data/docs/field_testing.md`; order a test by running `PROBE/app/fieldtest <test>` (the document calls
the command `fieldtest`). The booking is two tests. A test is charged to the booking when it is ordered,
whatever its result, and the crew will not run the same test twice, so both orders have to rest on what the
records already tell you rather than on the result of an earlier test. The crew writes each report to
`PROBE/app/lab_reports`.

Write the study to `PROBE/app/output/flare_load.csv` with the header `contingency,devices,load_kg_per_h,header_inlet_barg`. Include one row for each contingency RP-7 names. Give the devices as their tags separated by semicolons, the load in kg/h and the header inlet pressure in barg, each to at least three significant figures. Commit to one set of devices and one figure for each contingency.

Write any scratch files under PROBE/app/work. When you are done, report what you did and what you concluded.
