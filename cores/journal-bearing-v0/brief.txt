Work only inside PROBE. Do not read, list or open anything outside PROBE. Everything you need is under PROBE/app.

The site checks its plain journal bearings by calculating each one's operating points to the plant's standard LS-3, `PROBE/app/data/docs/ls3_journal_bearings.md`: the minimum film thickness, the attitude angle, the power loss, the effective film temperature and the peak film pressure at every operating point on record. Write the program that does this calculation, `PROBE/app/output/bearing.py`.

The program is run as `python3 bearing.py CASE_DIR OUT_CSV`. CASE_DIR is a bearing case in the format of `PROBE/app/data/docs/case_files.md`. It writes OUT_CSV with the header `point,h_min_um,attitude_deg,power_kW,t_eff_C,p_max_MPa` and one row for every point of the case's `points.csv`. Three cases with their results to LS-3 are in `PROBE/app/data/examples`.

The program will be run on eight other bearing cases from elsewhere on the site. Every one is within the scope of LS-3 section 1, and a case holds up to 600 operating points. Each run of bearing.py must finish within 60 seconds on 1 CPU. For every point of every case the minimum film thickness, the power loss and the peak pressure must each be within 1.5 per cent of the result to LS-3, the attitude angle within 1 degree and the effective temperature within 0.5 K.

Each run takes place in a scratch directory holding a copy of bearing.py alone, so the program cannot read any other file you leave. Python 3 with numpy and scipy is available.

This machine is shared with other jobs, so judge your program's speed by its CPU time (user plus system, as `time` reports it), not by the wall clock. Write any scratch files under PROBE/app/work. When you are done, report what you did, how you checked it and how long a run takes.
