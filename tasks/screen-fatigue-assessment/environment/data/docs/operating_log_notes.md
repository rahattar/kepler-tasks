# Daily operating log (operating_log.csv)

From the plant historian, one row per screen and day since commissioning, to 2026-10-31.
- h_empty: hours running with no feed. h_0_200 ... h_600_800: hours running with the belt-scale feed in that band,
  t/h; within a band the feed is spread evenly.
- starts: number of starts that day. S8 has been the pilot screen for the new historian since 2024-07-01; its rows
  from that date come from the new system's drive-event counter.
- S9's rows for 2024 are missing (historian disk failure); its 2024 operation is in the screen house production
  report (s9_production_2024.md).
