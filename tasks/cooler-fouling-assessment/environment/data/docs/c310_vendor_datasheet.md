# E1 and E10 (model C-310): vendor datasheet extract

| item | C-310 |
|---|---|
| heat-transfer area | 110 m2 |
| design cooling-water flow | 220 m3/h |
| design glycol flow | 75 m3/h |
| clean overall coefficient at design flows | 1490 W/m2K |
| clean tube-side / shell-side film coefficients at design | 3570 / 2900 W/m2K |
| tube wall | 0.05 m2K/kW |
| tube-side pressure drop at design, clean | 38 kPa |

Rated by the vendor's thermal program for the design fluids; not measured on site, and this one sheet is the only
rating either cooler has. E1 and E10 were built to the same drawing in one batch and the vendor ran its program
once for the pair. Their works test certificates agree to within about one per cent on clean tube-side pressure
drop at the design flow, on tube count and on bundle weight. The same exponents as the C-200 apply (0.8 tube
velocity, 0.6 glycol flow, 1.8 pressure drop).
