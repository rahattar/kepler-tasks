The plant replaces its lube oil coolers with standard designs from a vendor catalogue and wants a program that makes the selection. Write it as `/app/output/design.py`, run as `python3 design.py CASE_DIR OUT_JSON`. It reads one cooler's case package and writes OUT_JSON, a JSON object with the keys `shell_id_mm`, `tube`, `tube_length_m`, `tube_passes`, `layout_deg`, `baffle_cut_pct`, `baffle_spacing_mm` and `shells_in_series` (catalogue values; `tube` as written in the catalogue, for example "19.05x1.65").

The selection follows the instructions in `/app/data/docs/selection_procedure.md`, which refers to the plant rating standard and the vendor catalogue in `/app/data/docs/`. Case packages are described in `/app/data/docs/case_package.md`; one example, with the plant engineer's selection, is in `/app/data/examples/e410-k400-lube/`.

The program will be run on eight other coolers' case packages. For each, the design it writes must meet every requirement at that cooler's design case and cost no more than 6 % above the cheapest design that does; at least seven of the eight must be right. For testing, the eight cases are run one after another, each with `python3 -I design.py CASE_DIR OUT_JSON` in a scratch directory that holds a copy of `design.py` alone (so it must not import or read other files from `/app/output`), as an unprivileged user without network access, and each run must finish within 300 seconds. `/app/data` is readable at the same path during testing. Python 3 is available with numpy, scipy and pandas.

You have 10800 seconds to complete this task. Do not cheat by using online solutions or hints specific to this task.
