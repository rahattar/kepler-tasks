The hardening shops of a works group had most of their quench oil systems drained and refilled, and the oil now in the tanks has to be sampled before anything can be calculated with it. Each site sends its records in as a package, in the format of `/app/data/docs/site_package.md`: its quench tanks and oil systems, the oil work done, the laboratory analyses on file and the loads on record. With the oil of every tank settled, every load is calculated to the group's standard HT-5, `/app/data/docs/ht5_bar_quench.md`: the time the centre of the bar takes from 800 C to 500 C, its cooling rate through 700 C, the largest difference between centre and surface, the surface temperature when the centre reaches 500 C, and the time for the centre to reach 150 C.

Write `/app/output/quench.py`, the program that does this for one package. It is run as `python3 quench.py PACKAGE_DIR OUT_CSV` and writes `OUT_CSV` with the header `load,t85_core_s,cr700_core_K_s,dT_max_K,ts_core500_C,t150_core_s` and one row for every load of the package's `loads.csv`, the values as decimal numbers in the units the header names; `OUT_CSV` must be no larger than 4194304 bytes. While it runs, the program may place the one laboratory order that `/app/data/docs/site_package.md` describes, with the `labsample` command, which is installed and on the PATH wherever the program is run.

Two packages with their results to HT-5 are in `/app/data/examples/north_works` and `/app/data/examples/east_works`, and a package without results is in `/app/data/pending/west_quarry`.

The program is then run on the packages of six other sites, in the same format. Every load is within the scope of HT-5 section 1, and a package holds up to 3,000 loads. Each run of quench.py must finish within 50 seconds on 1 CPU. For every load of every package, the two times, the cooling rate and the largest temperature difference must each be within 1.5 per cent of the result to HT-5, and the surface temperature within 3 K.

Each run takes place in a scratch directory holding a copy of `quench.py` alone, under an unprivileged user without network access, with the package read-only, and must end with exit status 0. `/app/data` is readable at the same path, and Python 3 with numpy, scipy and pandas is available.

You have 28800 seconds to complete this task. Do not cheat by using online solutions or hints specific to this task.
