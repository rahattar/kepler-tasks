Work only inside PROBE/app. Do not read, list or open anything outside PROBE/app, except by running the `nertest` command as described.

A gas works closes the liquid nitrogen tanks at a depot for a holding period while the depot's recovery compressor is overhauled. Each period is planned by calculating every tank to the works standard CS-4, `PROBE/app/data/docs/cs4_closed_holding.md`: its pressure at the end of each day, the nitrogen its relief valve vents, and its state. A depot sends its tanks in as a package, in the format of `PROBE/app/data/docs/depot_package.md`.

Write `PROBE/app/output/holding.py`, the program that makes this calculation for one package. It is run as `python3 holding.py PACKAGE_DIR OUT_CSV` and writes OUT_CSV with the header `record,tank,day,p_barg,vented_kg,state` and one row for every tank and every day of the period, the values in the units the header names. While it runs, the program may place the one test order that `PROBE/app/data/docs/depot_package.md` describes, with the `nertest` command, which is on the PATH when the program is run and is at `PROBE/app/nertest` here.

Two packages with their results to CS-4 are in `PROBE/app/data/examples/north_moor` and `PROBE/app/data/examples/east_basin`, and a package without results is in `PROBE/app/data/pending/west_quarry`.

The program will be run on the packages of six other depots, in the same format. Every tank is within the scope of CS-4 section 1. Each run of holding.py must finish within LIMIT seconds on 1 CPU. For every record of every package, the pressure must be within 0.15 bar of the result to CS-4, the vented nitrogen within 5 per cent or 100 kg of it, whichever is larger, and the state must be `full` on exactly the days CS-4 gives `full`.

Each run takes place in a scratch directory holding a copy of holding.py alone, so the program cannot read any other file you leave. Python 3 with numpy and scipy is available.

This machine is shared with other jobs, so judge your program's speed by its CPU time (user plus system, as `time` reports it), not by the wall clock. Write any scratch files under PROBE/app/work. When you are done, report what you did, how you checked it and how long a run takes.
