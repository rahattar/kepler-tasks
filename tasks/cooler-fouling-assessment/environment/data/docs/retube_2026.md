# Ribbed-tube retube (EC-2026-031): engineering change summary

E3, E7 and E8 were retubed in April and May 2026 with internally ribbed tubes of the same outside diameter and tube
count, to recover cooling capacity in summer. Ribs raise the tube-side film coefficient and the tube friction
factor. The tubes came from three production lots (A, B, C) whose rib height differs (incoming inspection: 0.3 to
0.7 mm), so the gain is not the same from unit to unit. All three lots are the same rib form (helix angle and rib
pitch to the same drawing); only the rib height changes. For one rib form the tube maker's loop tests tie the two
gains to each other, both taken at the same tube velocity:

    h_ribbed / h_plain - 1 = K * (f_ribbed / f_plain - 1)

with a single coefficient K for the form. K therefore holds for all three lots whatever their rib height, and a
lot's rib height sets the size of both gains together. The maker gives the relation but no value of K for these
lots, and none has been measured on site. The shell side and the bundle layout were not changed. No clean
performance test has been made since the retube.
