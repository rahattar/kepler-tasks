# Pump bank wear assessment: requirement (reliability engineering)

For every pump, the head deficit at 900 m3/h as the pump stands on 2026-11-02: the head it would deliver at
900 m3/h and 1480 rpm in as-new condition (wear rings at new clearance, impeller as installed) minus the head it
delivers as found, in metres. Each value must be within 0.3 m of the pump's true deficit. The 2027 overhaul list
is ranked on these figures.
